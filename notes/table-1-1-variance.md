# 表 1-1 を同じプロンプトで 3回取り出したときの揺れ（2026-11-03）

表 1-1 を取り出し直したとき、面積の単位が「km2」から「km²」に変わった（[表 1-2 の結果](./table-1-2-first-run.md)）。そのときはプロンプトも変えていたので、回ごとの揺れかどうかを分けられなかった。そこで、プロンプトを変えずに同じ入力で 3回呼んだ。

## 測り方

- 入力・モデル・比べ方は[表 1-1 の最初の結果](./table-1-1-first-run.md)と同じ（30 ページだけの PDF、`gemini-3.8-flash`、[decisions/0004](../decisions/0004-compare-cells.md)）
- プロンプトは PR #14 のあとのもの（列の見出しの注記の書き方を足したもの）。3回とも同じ
- 3回続けて呼び、回ごとの出力を `data/output/runs/1-1/run1.csv`〜`run3.csv` に残した
- 揃える前の書き方は、出力の CSV と正解の CSV を、列ごとに文字のまま比べた

## わかったこと

- 「km2」と「km²」の違いは、プロンプトのせいではなく回ごとの揺れだった。同じプロンプトの 4回のうち 2回が「km²」
- 揺れは単位の書き方だけで、値・見出し・注記には出なかった。比べる仕組みで NFKC に揃えているので、一致率には響かない（2026-11-03 に、書き方の違いはこのままにすると決めた）
- 出力のトークンは、CSV にしたときの中身が同じでも 3,207〜5,604 と大きく違った（1回目と 2回目は中身が同じで 4,113 と 3,207）。JSON の空白や改行の入れ方が回によって違うためと推定（応答の生の JSON は残していないので確かめていない）
- 思考のトークンも 1,784〜2,685 と揺れる。1回あたりの料金は $0.020〜0.029 で、1回だけ測った数字は ±20% ほど動くとみておく
- 時間は 42〜46 秒で、揺れは小さい
