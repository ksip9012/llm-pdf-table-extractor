# 表 1-8 を LLM で取り出した最初の結果（2026-11-03）

表 1-8（気象官署別気温（令和6年）、PDF の 33 ページ）を Gemini に読ませ、正解（`data/truth/1-8.csv`）と比べた。611 セル（47 官署 × 13列）と、表 1-1（96 セル）の 6倍ほどある表で、出力が長いときの精度・料金・時間を見る。

## 測り方

[表 1-1 の最初の結果](./table-1-1-first-run.md)と同じ（1ページの PDF、`gemini-3.8-flash`、1回、[decisions/0004](../decisions/0004-compare-cells.md) で比べる。料金は 100万トークンあたり入力 $0.75・出力 $3.75 で計算）。

プロンプトに次の 2つを足した。正解の見出しや値は渡していない。

- 値に付いた注記の印（「a)」など）は値から外し、印の文字をそのセルの notes に書く
- 複数の列をまとめる見出しに単位が書かれていれば、その下の列すべての unit に書く

列の見出しが 2段（「気温（℃）」の下に「平均」「1月」…）のとき、まとめの見出しを column_label に含めるかは、プロンプトで伝えていない。LLM がどう書くかを見るため。

## 結果

| 項目 | 表 1-8 | 表 1-1（最初） |
| --- | --- | --- |
| 正解のセル / 出力のセル | 611 / 611 | 96 / 96 |
| 値の一致率 | 100.0%（611 / 611） | 100.0% |
| すべて合ったセル | 611 | 96 |
| 食い違い | 0 | 0 |
| 処理時間 | 141.1 秒 | 33.3 秒 |
| トークン（入力 / 出力 / 思考） | 1,105 / 24,116 / なし | 1,011 / 4,314 / 1,783 |
| 料金 | 約 $0.091 | 約 $0.024 |

- 出力の CSV は、揃える前の文字でも正解とファイルごと同じだった（見出し・値・単位・注記・並び順）
- 那覇の 11月の「a)23.9」は、値「23.9」と notes「a」に分けて出た
- 列の見出しは「平均」「1月」…で、まとめの見出し「気温」は含めなかった。単位はすべて「℃」
- 負の値（札幌の 1月の「-1.8」など）、「19.0」のような末尾の 0 も、PDF のとおりに出た
- 出力が途中で切れたり、待ち時間で止まったりはしなかった

## わかったこと

- セルが 6倍になっても、値の一致率は落ちなかった。表 1-8 は見出しが素直（行 = 官署、列 = 月）で、組も 1つなので、セルが多いことだけでは精度は落ちないとみる
- 時間と料金は、ほぼ出力のトークン（セルの数）に比例した。1セルあたり、出力は約 39 トークン（表 1-1 は約 45）、時間は約 0.23 秒、料金は約 $0.00015
- 思考のトークンが出なかった（`usage_metadata` の `thoughts_token_count` が None）。表 1-1・1-2 では毎回 800〜2,700 あった。なぜ思考しなかったのかは確かめていない（モデルの側で決まる）
- 1回 141 秒かかる。表を増やして何度も回すときは、待ち時間が効いてくる

## プロンプトを変えたあとの表 1-1・1-2

足した 2行は表 1-1・1-2 には当てはまらないが、念のため取り出し直した（各 1回）。

| 表 | 値の一致率 | すべて合ったセル | 時間 | トークン（入力 / 出力 / 思考） | 料金 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | 100.0%（96 / 96） | 96 | 33.4 秒 | 1,103 / 4,314 / 981 | 約 $0.021 |
| 1-2 | 100.0%（98 / 98） | 98 | 35.7 秒 | 1,100 / 5,223 / 765 | 約 $0.023 |

- どちらも食い違いは 0 で、プロンプトを変えても結果は落ちなかった
- 揃える前の書き方は、今回も回ごとに違った。どちらも比べる仕組みで揃えているので一致に数える
  - 表 1-1: 面積の単位が「km2」に戻った（前回は「km²」。[揺れの記録](./table-1-1-variance.md)で見た回ごとの揺れ）
  - 表 1-2: 「-」の 48 セルが、末尾に改行の付いた「-\n」で出た（前回は前後に空白の付いた「 - 」）。CSV では値に改行が入るので、`data/output/1-2.csv` の行の数が増えている
- 表 1-2 の出力のトークンは 5,223 で、前回（3,852）より多い。中身は「-」の空白・改行の違いだけなので、書き方の揺れがトークンにも出ている
