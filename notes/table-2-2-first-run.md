# 表 2-2 を LLM で取り出した最初の結果（2026-11-03）

表 2-2（都道府県別人口と人口増減率、PDF の 38 ページ）を Gemini に読ませ、正解（`data/truth/2-2.csv`）と比べた。Step2 の最後の表で、列の見出しが 3段ある（[見出しが複雑な表の見比べ](./complex-table-survey.md)）。見出しが複雑な表で精度が落ちるかを見る。

## 測り方

[表 1-1 の最初の結果](./table-1-1-first-run.md)と同じ（1ページの PDF、`gemini-3.8-flash`、1回、[decisions/0004](../decisions/0004-compare-cells.md) で比べる。料金は 100万トークンあたり入力 $0.75・出力 $3.75 で計算）。

プロンプトの、列の見出しと単位の書き方を、[decisions/0006](../decisions/0006-multi-level-column-labels.md) に合わせて書き直した。正解の見出しや値は渡していない。

- 列の見出しが上下の段にわかれているときは、上の段から順に「/」でつなぐ。名前の書かれていない枠は飛ばす。表の値の列すべてをまとめる見出しはつながない
- 単位は、列の見出しの下に単位だけを書いた「(…)」と、表の値の列すべてをまとめる見出しのかっこの中にあるものだけ。列の見出しと同じ枠の中のかっこ書きは、単位に見えても column_label に残す
- 見出しの中の改行と空白は外す

| すべて合ったセル | 384 |

- 出力の CSV は、揃える前の文字でも正解とファイルごと同じだった（見出し・値・単位・注記・並び順）
- 列の見出しは 8列とも正解と同じ形で出た（「国勢調査人口/平成27年」「国勢調査人口/人口集中地区」など）。名前のない枠も飛ばされた
- 2列ある人口増減率は「国勢調査人口/人口増減率（平成27～令和2年）」と「令和6年推計人口/人口増減率（対前年）（人口1,000につき）」に分かれた。後者の「（人口1,000につき）」は column_label に残り、unit は空だった
- 列の注記「1)」「2)」は、人口集中地区・人口密度の列のセルすべてに付いた
- 大阪府の「-0.0」も、PDF のとおりに出た

## わかったこと

- 見出しが 3段・同じ名前の列が 2つある表でも、値の一致率は落ちなかった。第1章の 3表と合わせて、Step2 の 4表すべてが 100% になった
- ただし、プロンプトの書き方の決まり（「/」でのつなぎ方、どのかっこ書きを単位にするか）は、この表を見て正解の形を決めたあとに、同じ決まりを書き足したもの。LLM は決まりを伝えれば守れる、ということは言えるが、決まりを伝えなかったときに LLM がどう書くか（どれくらい正解とずれるか）はまだ見ていない
- 精度の差は「値を読み取れるか」より「見出しをどう書くかを、正解とそろえられるか」で出そうだ、とみている（推定）。第1章で見えた揺れ（「km2」「km²」、「-」の空白）も、値ではなく書き方だった
- 時間と料金は、これまでと同じくセルの数にほぼ比例した（1セルあたり、出力 約 42 トークン、約 0.26 秒、約 $0.00017）

## プロンプトを変えたあとの第1章の 3表

単位の書き方の行も書き直したので、第1章の 3表も取り出し直した（各 1回）。

| 表 | 値の一致率 | すべて合ったセル | 時間 | トークン（入力 / 出力 / 思考） | 料金 |
| --- | --- | --- | --- | --- | --- |
| 1-1 | 100.0%（96 / 96） | 96 | 34.9 秒 | 1,227 / 4,314 / 1,393 | 約 $0.022 |
| 1-2 | 100.0%（98 / 98） | 98 | 24.3 秒 | 1,224 / 3,804 / 889 | 約 $0.019 |
| 1-8 | 100.0%（611 / 611） | 611 | 88.4 秒 | 1,229 / 17,388 / 493 | 約 $0.068 |

- 3表とも食い違いは 0 で、プロンプトを変えても結果は落ちなかった
- 揃える前の書き方: 1-1 の単位は今回「km²」（前回は「km2」。回ごとの揺れ）。1-2 の「-」は空白も改行もなく、正解と文字のまま同じだった。1-8 は前回とファイルごと同じ
- 1-8 は、出力の中身が前回と同じなのに、出力のトークンが 24,116 → 17,388、時間が 141 秒 → 88 秒に減った。思考は前回なし、今回 493。[揺れの記録](./table-1-1-variance.md)で見た「中身が同じでもトークンが揺れる」が、大きい表ではそのまま時間と料金の差になる
