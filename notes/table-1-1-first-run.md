# 表 1-1 を LLM で取り出した最初の結果（2026-11-03）

表 1-1（都道府県別面積、PDF の 30 ページ）を Gemini に読ませ、正解（`data/truth/1-1.csv`）と比べた。表を取り出す → 比べるの流れが最後まで通るかを確かめるための 1回目。

## 測り方

- 入力: `data/raw/26nihon.pdf` の 30 ページだけを切り出した 1ページの PDF（約 608KB。[decisions/0003](../decisions/0003-gemini-with-single-page-pdf.md)）
- モデル: `gemini-3.8-flash`（Vertex AI、`location=global`）。Structured Output で 0002 の縦長の形を出させる
- 回数: 1回（料金がかかるため。回によって結果が揺れるかはまだ見ていない）
- 処理時間: `extract_cells` の呼び出し前後を `time.perf_counter` で測る。SDK の自動の再試行は切っていない（今回は 1回目の呼び出しで 200 が返った）
- トークン数: 応答の `usage_metadata` から、入力・出力・思考を分けて取る
- 比べ方: [decisions/0004](../decisions/0004-compare-cells.md)（見出しの組でセルを対応させ、値・桁・単位・注記を分けて数える）
- 料金: Gemini 3.8 Flash の Standard の料金（100万トークンあたり入力 $0.75、出力 $3.75。出力には思考トークンを含む。2026-12-31 までの価格で、2027-01-01 からは入力 $1.50・出力 $7.50）。[公式の料金表](https://aistudio.google.com/docs/pricing)で 2026-11-03 に確かめた。料金表は AI Studio のもので、Vertex AI でも同じ単価とみなして計算した（Step1 と同じ扱い。Vertex AI の料金表では確かめていない）

## 結果

| 項目 | 値 |

| 正解のセル / 出力のセル | 96 / 96 |
| 値の一致率 | 100.0%（96 / 96） |
| 桁まで合ったセル | 96 |
| すべて（値・桁・単位・注記）が合ったセル | 96 |
| 食い違い | 値 0・桁 0・単位 0・注記 0・足りない 0・余計 0 |
| 処理時間 | 33.3 秒 |
| トークン（入力 / 出力 / 思考） | 1,011 / 4,314 / 1,783 |
| 料金 | 約 $0.024（入力 約 $0.0008、出力と思考 約 $0.0229） |

- 並び順も正解と同じだった（左の組の上から下、次に中の組、右の組）。プロンプトで頼んだ順のまま
- 注記の印「1)」は、21 都道府県すべてで行の見出しから外され、番号が notes に入った
- 全国の千分比は「1000.00」で、PDF の桁のまま出た（xlsx は「1000」）

## わかったこと

- 最初に比べたとき、千分比の単位だけ 48 セルが食い違った。LLM は「0/00」、正解は「‰」だった。PDF の文字の層も xlsx の見出し（D5 など）も「(0/00)」で、ずれていたのは正解の側だった。正解を「0/00」に直し、単位が PDF に書かれているかを確かめるテストを足した
  - 正解を作るときに、PDF にない書き方を持ち込んでいた。値と行の見出ししか PDF と照らしていなかったので気づかなかった。LLM の出力と比べることで、正解の誤りも見つかる
- 入力のトークンは 1,011 と少なく、料金の 97% ほどは出力と思考の分。出力の 4,314 は、96 セルを 1つずつ JSON で書くため（見出しの組を毎回書く縦長の形の分だけ長い）。思考は料金の 28% ほど
- 切り出したページは 608KB と、本全体（約 3.4MB）の割に大きいが、入力のトークンには響いていない

## まだ見ていないこと

- 同じ入力で何回か呼んだときに、結果が揺れるか（Step1-A2 では、年月だけの日付の扱いが回によって揺れた）
- 見出しが複雑な表（行や列の見出しが 2段になっている表など）での精度。表 1-1 は見出しが 1段で、値もすべて数値
- 画像で渡す・抜き出した文字で渡すとの比較
