# 表 1-2 を LLM で取り出した最初の結果と、表 1-1 の取り出し直し（2026-11-03）

表 1-2（都道府県別島の数、PDF の 30 ページ）を Gemini に読ませ、正解（`data/truth/1-2.csv`）と比べた。表 1-1 になかった「-」の値・都道府県でない行（本州、四国、九州）・列の見出しの注記を扱えるか、同じページの表 1-1 と取り違えないかを見る。

プロンプトに、列の見出しの注記の書き方（[decisions/0005](../decisions/0005-column-notes.md)）と、単位が書かれていないときは空にすることを足したので、表 1-1 も取り出し直して結果が変わらないかを確かめた。

## 測り方

[表 1-1 の最初の結果](./table-1-1-first-run.md)と同じ（1ページの PDF、`gemini-3.8-flash`、1回ずつ、[decisions/0004](../decisions/0004-compare-cells.md) で比べる。料金は 100万トークンあたり入力 $0.75・出力 $3.75 で計算）。

## わかったこと

- 比べる仕組みで揃えている書き方の違いが、2つ出た。どちらも一致に数えられている
  - 表 1-2: 「-」の 48 セルすべてが、前後に空白の付いた「 - 」で出た。0004 で値の前後の空白を外して比べるので一致になる
  - 表 1-1 の取り出し直し: 面積の単位 48 セルが「km2」ではなく「km²」（上付きの 2）で出た。最初の回は「km2」だった。0004 で NFKC に揃えると「²」は「2」になるので一致になる。PDF の文字の層は「(km2)」で、紙面では上付きに見える字を LLM が見た目のまま写したと推定（ページを画像では見ていない）
- 表 1-1 は、同じ入力でも回によって単位の書き方が変わった。ただし今回はプロンプトも変えているので、回ごとの揺れか、プロンプトを変えたせいかは分けられない
- 思考のトークンは回によって 804〜2,318 と大きく違う。料金はおおむね出力（セルの数）で決まり、1表 $0.02 前後
- 「1行 = 1セル」の出力が CSV に入るとき、値の空白はそのまま残る（`data/output/1-2.csv` の「 - 」）。比べる前に揃えるのは 0004 の範囲で、出力の CSV は LLM が書いたまま残している
