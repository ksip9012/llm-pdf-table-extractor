# 0006. 段をまたいだ列の見出しは、上の段から「/」でつないで 1つの column_label にする

- Status: Accepted
- Date: 2026-11-03

## Context
[0002](./0002-truth-as-long-cells.md) で、列の見出しは「表に書かれたまま、単位は外して」column_label に持つと決めた。第1章の表は、列の見出しが 1段だった（1-8 の「気温（℃）」は表の値の列すべてをまとめる見出しで、単位を読むだけに使った）。

表 2-2（都道府県別人口と人口増減率、PDF の 38 ページ）は列の見出しが 3段ある。

- 「国勢調査人口」の下に「平成27年」「令和2年」、名前のない枠（その下に「人口集中地区」「人口密度」）、「人口増減率（平成27～令和2年）」
- 「令和6年推計人口」の下に「総人口」「人口性比（女性100に対する男性）」「人口増減率（対前年）（人口1,000につき）」

いちばん下の段だけを column_label にすると、どちらの調査の値かがわからなくなる。「人口増減率」は 2列あり、かっこ書きでしか見分けられない。

## Decision
段をまたいだ列の見出しは、上の段から「/」でつないで 1つの column_label にする。

- 例: 「国勢調査人口/平成27年」「国勢調査人口/人口集中地区」「令和6年推計人口/人口増減率（対前年）（人口1,000につき）」
- 名前のない枠は飛ばす。縦に結合された同じ見出しは 1回だけ書く
- 表の値の列すべてをまとめる見出し（1-8 の「気温（℃）」）はつながない。表題と同じ働きで、どの列でも同じになるため
- 見出しの中のかっこ書き（期間・定義・「人口1,000につき」など）は、見出しのまま column_label に残す。単位（unit）は、見出しの下の単位の行に書かれたものだけにする
- 見出しの中の改行と空白は外す（0002 の行の見出しと同じ）

## Consequences
- 「人口増減率」の 2列は「国勢調査人口/人口増減率（平成27～令和2年）」と「令和6年推計人口/人口増減率（対前年）（人口1,000につき）」になり、上の段とかっこ書きで見分けられる
- column_label が長くなる。LLM にも同じつなぎ方を伝える必要がある（表 2-2 を LLM で取り出すときにプロンプトに足す）。つなぎ方が少しでも違うと、比べる仕組み（[0004](./0004-compare-cells.md)）では足りないセルと余計なセルの両方に数えられる
- 単位の行がない列（人口性比・対前年の増減率）は unit が空になる。「人口1,000につき」を単位とみなす LLM の出力は、その列が食い違いになる
- 第1章の 3表の正解は変わらない（1-8 の「気温（℃）」はつながないため）
- 選ばなかった案: いちばん下の段だけ（「人口増減率」がかっこ書きでしか見分けられず、ほかの表では同じ名前がぶつかりうる）、上の段を別の列（column_group など）にする（0002 の列が増え、段が 3つ以上の表で足りなくなる）、「〜につき」を単位にする（どのかっこ書きが単位かの線引きが要る）
