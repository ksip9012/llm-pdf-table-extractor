# 0002. 正解は、どの表でも同じ縦長の形（1行 = 1セル）で持つ

- Status: Accepted
- Date: 2026-11-03

## Context
PDF の表から LLM で取り出したデータの精度を、xlsx から作る正解と比べて測る。まず表 1-1（都道府県別面積）で一通り作り、そのあと第 1 章のほかの表や、見出しが複雑な章（人口・家計など）に広げる。表ごとに列が違うので、正解の形を表ごとに変えると、比べる仕組みも表ごとに作ることになる。

表 1-1 の PDF（30ページ）と xlsx を見比べると、次のことがわかった。

- 「都道府県・面積・千分比」の組が横に 3つ並んだ形。注記の印「1)」が都道府県名の横に付く
- xlsx の 24 行目に、PDF の表 1-1 にない行（「三重, 540」。次の表 1-2 の値）が混ざっている
- 全国の千分比が、PDF は「1,000.00」、xlsx は「1000」と書き方が違う。xlsx の表示形式は `#,##0.00`

## Decision
正解は、どの表でも同じ縦長の形で持つ。

- 1行 = 1セル。列は `table_id`・`row_label`・`column_label`・`value`・`unit`・`notes`
- 表ごとに `data/truth/<表の番号>.csv`（UTF-8）
- 値は文字列で持つ。数値は桁区切りを外し、小数の桁は xlsx の表示形式に合わせる（PDF に書かれた桁）。「-」などの記号はそのまま。数値として比べるのは、比べる仕組みの側で行う
- 行と列の見出しは、表に書かれたまま（都道府県コードなどに直さない）。列の見出しから単位は外して `unit` に置く
- 注記は番号で持ち、そのセルにかかる番号を `notes` に `;` 区切りで書く。行にかかる注記は、その行のセル全部に付ける
- 表の外の情報（章・表題・PDF のページ・基準日・注記の中身・資料）は `data/truth/<表の番号>.meta.json` に置く
- 正解の基準は「PDF の表に書かれていること」。xlsx は数値を写すための材料として使い、PDF にない行（xlsx の余計な行）は入れない

## Consequences
- LLM の出力も同じ形で出させれば、どの表でも「セルが合っているか」を同じ仕組みで数えられる
- 表ごとの整然データ（1行 = 1都道府県など）が要るときは、この形から作れる
- 値を文字列で持つので、「1000」と「1,000.00」の違いや小数の誤差を正解に持ち込まない
- xlsx から正解を作る処理は、表ごとに置き場所（どのセルからどのセルか）を書く必要がある。xlsx の余計な行に気づけるよう、正解の値が PDF のページに書かれているかを確かめるテストを置く（PDF がある手元だけで動く）
- 選ばなかった案: 表ごとの整然データ（比べる仕組みを表ごとに作ることになる）、両方を持つ（作るものが 2つになる）
